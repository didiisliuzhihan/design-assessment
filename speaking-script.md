# Harbor Rooms 英文口播练习稿

这份稿子替代本次模拟包中的视频。正式测评仍需按实际任务录制；目前未核实正式视频时长、是否必须连续录制或是否允许剪辑。以下分段和长短版本是练习安排，不是正式录制规则。

`/` 表示短停顿，`//` 表示换段稍长停顿。不要读斜线或段落标题。数字可以按英文词读，不必加快。以你实际录制的语速安排时间，提前留出上传和链接检查时间。

## 主口播稿

### 介绍与建议

Hi, I'm Zhihan. /  
For this practice, / I focused on quote approval. //

My recommendation is to bring the quote /  
and its supporting information together. /  
AI helps organize the information. /  
The manager still makes the decision. //

### 证据与边界

The interviews suggest that managers sometimes need /  
to check several sources before approving a quote. /  
This may slow down the process. //

One log shows more than two hours /  
between the approval request and the decision. /  
But this does not mean /  
the manager spent all that time checking information. /  
Some of it may have been waiting time. //

### 方案与修改

The prototype shows the customer request, /  
the quote, the price source, /  
the approval rule, and linked communication. /  
The manager can check the original material /  
and flag anything that needs clarification. //

I removed the two general required checkboxes. /  
They could become routine clicks. /  
Checking a box does not prove /  
that someone actually reviewed the information. //

If important information is missing, /  
the manager can send the quote back. /  
Approval does not send an email /  
or reserve the venue. //

### 本次演练发现

In the practice walkthrough, /  
the customer asked for a fifteen percent discount /  
and free cancellation until three days before the event. /  
The AI summary missed the cancellation change. /  
The quote still said seven days. //

I would return it for revision. /  
The cancellation change also needs manager approval. /  
This showed why the original source matters. //

### 下一步验证

Next, I would test with real managers. /  
I would check whether they find the right information, /  
spot important differences, /  
and understand what to do next. //

I have not measured a time saving /  
or a reduction in errors. /  
Those are outcomes I would test. //

## Stakeholder 追问练习

以下问题与回答是模拟练习，不是 Ajaia 已公布的题目。回答的结构是先承认目标，再给证据、取舍和下一步。

### 我要求的是提醒功能

**Daniel:** I asked for more reminders. Why are you changing the review screen?

**Response:**

I agree that reminders can help after an interruption. /  
But they cannot supply missing information. /  
The interviews describe a problem finding approval evidence. /  
I would test that first, /  
while checking how much delay comes from manager availability. //

### 为什么不让 AI 全部自动批准

**Daniel:** Why can't AI approve all the quotes?

**Response:**

The current rules already let staff send standard quotes. /  
Larger discounts and cancellation changes need a manager. /  
AI can help prepare the information, /  
but the manager should make those decisions. /  
I would evaluate any new automation separately. //

### 只有两份访谈够吗

**Daniel:** You only have two interviews. How confident are you?

**Response:**

They give me a reason to investigate this problem. /  
They do not prove it is the biggest cause of delay. /  
I would review recent cases /  
and separate waiting time from active review time. /  
I would change priorities if the evidence pointed elsewhere. //

### 页面会不会增加工作

**Daniel:** Isn't this just more work for the manager?

**Response:**

It could be. /  
That is why I removed the general required checkboxes. /  
I would compare the effort of finding information /  
and check for missed conditions. /  
If this adds work without helping the decision, /  
I would revise it. //

### 能证明它更快吗

**Daniel:** Can you prove that this is faster?

**Response:**

Not yet. /  
This was a practice walkthrough, /  
not a timed study with managers. /  
I found one simulated omission. /  
I would need a baseline and user testing /  
before reporting an improvement. //

## 录制前自检

- 主张与提交稿一致，保留 may、sometimes、not yet 等必要边界。
- 说的是本次 guided practice，不声称完成真实经理测试。
- 演示页面时提前选好案例，并检查口播中的数字与当前页面一致。
- 按实际题目要求安排视频内容；正式提交时把真实视频链接放到文档顶部。
- 使用你能自然讲出的短句，句间可以停顿。不要把未知的一次录成要求当作已确认规则。
